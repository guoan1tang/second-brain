# 🧠 第二大脑 · 主页

> 一个模仿人类大脑记忆结构、可被 agent 读写的个人记忆系统。

## 记忆分区

| 文件夹 | 大脑对应 | 说明 |
|--------|---------|------|
| `00-Inbox · 收件箱` | 感觉/工作记忆 | 随手记的碎片,待巩固 |
| `05-Core · 核心记忆` | 核心记忆 | 一生难忘,永不衰减 |
| `10-Semantic · 语义记忆` | 语义记忆 | 事实、概念、你是谁 |
| `20-Episodic · 情景记忆` | 情景记忆 | 何时何地发生了什么 |
| `30-Procedural · 程序记忆` | 程序记忆 | 怎么做某事(SOP) |
| `40-Entities · 实体图谱` | 知识图谱 | 人/地/物/概念及其关系 |
| `90-Consolidation · 巩固日志` | 巩固/纠错留痕 | 巩固记录与更正日志 |

> 每个分区里都有一篇 `_关于` 笔记说明用途。

## 三大机制

1. **巩固**:定期把收件箱碎片提炼、晋升为长期记忆
2. **遗忘曲线 + 间隔重复**:记忆有强度,会衰减,到期回顾
3. **线索触发**:一句话/一种气味,通过 `cues` 唤醒整段记忆

## 模板(`_templates/`)

`Cmd+P` → 「插入模板」:
- `标准记忆模板` — 日常记忆
- `核心记忆模板` — 一生难忘
- `实体模板` — 人/地/物/概念
